Learn what SENTINEL sees

EMA 20 / EMA 50: compares shorter- and longer-term trend. EMA 20 above EMA 50 suggests an upward trend; below suggests downward pressure.

RSI 14: momentum gauge from 0–100. Above 70 can indicate stretched upward momentum; below 30 can indicate stretched downward momentum. Neither is an automatic reversal signal.

Relative volume: latest hourly volume compared with the previous 20 hourly candles. Higher volume can add context, but does not prove a move will continue.

BUY WATCH / SELL WATCH: a rule-based setup worth studying. HOLD: conditions are mixed or insufficient. No signal is guaranteed.

Data: Coinbase public market candles. No account connection, API key, order placement or financial advice. Data can be delayed or unavailable. Keep this app open or refresh manually; this starter version does not run a 24/7 background service or send push alerts.
